# 메뉴 대검수·차별화 업그레이드 기획서

> 2026-07-24. 8개 메뉴 전 항목을 검수하고, 메뉴마다 "다른 솔루션에 없는 독창적·실용적 차별점"을 최소 1개 이상 구현한다.
> 원칙: ①모든 항목 Playwright 실입력 검수(버튼만 있고 안 되는 것 제로) ②차별화는 경쟁 분석 근거 필수 ③메뉴 단위 커밋+검증.
> 경쟁 비교군: MS Word, 한글(HWP), Notion, Obsidian, Typora, Google Docs, iA Writer.

## 1. 서식 (Toolbar.tsx ~719행)
**현황**: 마크 5종, 제목 1~3, 정렬 4종, 한국어 타이포(자간·장평·들여쓰기·단락간격·글자효과·강조상자), 문서 스타일, 서식 지우기, ¶ 표시.
**검수 포인트**: 자간/장평/단락간격이 window.prompt 잔존인지(→askText 전환), 글자 효과·강조 상자 실동작, 서식 지우기가 콜아웃/수식 등 특수 노드를 파괴하지 않는지.
**경쟁 대비 이미 차별적**: 자간·장평은 Word(한글판)·HWP만 있고 웹 에디터엔 거의 없음.
**차별화 구현**:
1. **서식 복사 (포맷 페인터)** — useFormatPainter 훅이 이미 존재하나 메뉴 미노출. 메뉴+단축키 노출, "더블 실행 시 연속 적용"(Word 동일) 지원.
2. **내 스타일 (스타일 세트)** — 현재 선택 텍스트의 서식(굵기·색·크기·자간·장평)을 이름 붙여 저장 → 원클릭 재적용. localStorage 영속. Word 스타일 갤러리의 간이판 — 브라우저 메모장 중 유일.

## 2. 삽입 (~751행)
**현황**: 표/이미지/링크/목차/구분선, 리스트 4종+코드, 각주·인용·책갈피·텍스트상자, 수식·Mermaid·콜아웃·임베드, 날짜·특수문자·빠른메모.
**검수 포인트**: 책갈피·텍스트상자·구분선 스타일 실동작, 임베드 XSS 살균 유지, '수식(LaTeX)' 항목을 수식 스튜디오로 연결(현재 askText).
**차별화 구현**:
1. **CSV/TSV → 표 자동 변환** — 스프레드시트에서 복사한 데이터를 "표로 붙여넣기" 메뉴로 즉시 표 변환(구분자 자동 감지, 첫 행 헤더 옵션). Notion도 CSV 붙여넣기는 일반 텍스트가 되는 케이스 많음.
2. **수식 삽입을 수식 스튜디오로 통일** — 삽입 메뉴의 수식(LaTeX)이 스튜디오를 열도록.

## 3. 페이지 (~786행)
**현황**: 크기/배경/여백 설정(모두 같은 모달), 페이지 구분, 다단, 러닝 헤더, ¶, 인쇄 미리보기/인쇄. 이미 Word 초과(거터·워터마크·번호형식·첫페이지 제외·여러쪽보기·자동 여러쪽).
**검수 포인트**: 세 항목이 같은 모달을 여는데 해당 섹션으로 스크롤/포커스되는지.
**차별화 구현**: **섹션 딥링크** — "여백 설정" 클릭 시 페이지 설정 모달이 여백 섹션으로 자동 스크롤+하이라이트.

## 4. 미디어 (~803행)
**현황**: 이미지 2종, YouTube, 화면 캡쳐, 갤러리, 음성입력/TTS/녹음/회의·강의노트, 파일 첨부, 그림판/포스트잇, AI 이미지(aiImageStub — 이름부터 의심).
**검수 포인트**: 화면 캡쳐·갤러리·녹음·AI 이미지 실동작(스텁이면 실구현 or 제거), '손글씨/스케치'와 '그림판'이 같은 onPaint 중복.
**차별화 구현**: **문서 이미지를 그림판에서 주석 편집** — 문서 속 이미지 선택 → "그림판에서 편집" → 화살표·박스·텍스트 주석 후 원자리 교체. (Word 불가, Notion 불가 — 스크린샷 주석 도구를 내장 그림판과 연동하는 독창 기능)

## 5. 도구 (~829행)
**현황**: 팔레트, AI 2종, 검색/찾아바꾸기/링크검사, 통계/히트맵/정보/diff/워드클라우드, 번역/맞춤법, 마인드맵/플래시카드, OCR/템플릿/스니펫/매크로/포모도로.
**검수 포인트**: 워드클라우드·플래시카드·포모도로 실동작.
**차별화 구현**: **문서 건강 점수** — 논문 검사기를 일반 문서용으로 일반화: 가독성(문장 길이 분포), 구조(제목 계층), 깨진 링크 수, 캡션 없는 이미지, 마지막 백업 경과를 0~100점+개선 제안으로. 어떤 메모 앱에도 없는 기능.

## 6. 보기 (~860행)
**현황**: 인쇄/초안, 집중/읽기 모드, 사이드바, 눈금자, 줌 세트, 목차, MD/인쇄 미리보기, ¶, 제목 번호.
**여러쪽보기 재설계 (2026-07-25)**: 줌≤50% 전용 읽기 전용 오버레이가 "실사용 불가" 피드백 → HWP 쪽모음식 사이드 패널(PageThumbnailPanel)로 교체. 편집과 항상 공존, 라이브 축소판, 클릭 이동(줌 유지), 현재 쪽 하이라이트, 보기 메뉴 토글 + 줌 50% 이하 진입 시 자동 열림.
**차별화 구현**: **타자기 모드** — 커서 줄을 화면 중앙에 고정(입력 시 자동 스크롤), iA Writer·Obsidian(플러그인)의 상징 기능. + **현재 문단 하이라이트**(집중 모드에서 커서 문단 외 흐리게 — iA Writer 포커스 모드 동일 수준).

## 7. 파일 (~889행)
**현황**: 새/열기/저장/다른이름, 인쇄/PDF/HTML/MD/HWPX/DOC 내보내기, Gist/공유링크/JSON 백업/v1 가져오기, 버전/잠금/휴지통/정보.
**검수 포인트**: HWPX·DOC 내보내기 산출물 유효성, 열기/저장 실동작.
**차별화 구현**:
1. **LaTeX(.tex) 내보내기를 파일 메뉴에도 노출** (이미 구현됨 — 논문 메뉴에만 있음).
2. **원클릭 전체 내보내기** — 현재 메모를 MD+HTML+PDF(tex 포함) 형식별로 한 번에 받는 "모든 형식 내보내기". HWPX까지 포함하면 국내 사용자에게 유일무이.

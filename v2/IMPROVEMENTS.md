## 2. 높음 결함 수정 (기능 접근 불가·오배선)

- **CMS 버튼이 앱을 이탈** (`/admin` 하드코딩 → dev 서버에서 base 경로 무시) → `origin` 절대경로 + 새 탭
- **홈 허브가 죽은 버튼** (`window.open("")` 빈 창) → 인앱 최근 메모 드롭다운으로 교체
- **헤더 검색 버튼이 웹 검색을 엶** (전체 검색과 오배선) → 전체 검색 패널로 재연결
- **저장 배지가 항상 "저장 안 됨"** (파일 저장 전엔 IndexedDB 자동저장 상태 미반영) → "자동 저장 · HH:MM"
- **글자 효과 침묵 실패** (전역 `.ProseMirror` 스타일이라 실효 없음) → `TextShadow` 확장으로 선택 영역에만 적용
- **읽기 모드가 편집 가능** (CSS만 있고 contenteditable 미차단) → 읽기 모드 시 `contenteditable=false`
- **인쇄 미리보기 0페이지** (Paged.js CDN 차단 환경에서 조용히 실패) → pagedjs 로컬 번들 인라인 주입 + 실패 시 명시적 안내
- **논문 메뉴 라벨-동작 불일치** ("논문 시작"이 인용 관리 패널만 엶) → 정직한 라벨로 정정
- **역할 템플릿 제목-내용 불일치** (개발자 "기술 스펙"이 PRD를 참조) → 전용 techSpec 템플릿 신설

## 3. 중간·낮음 결함 수정

- 활동 히트맵 요일 라벨 1행 오프셋 정정
- 마인드맵 루트 라벨을 메모 제목으로
- 태그 카운트가 삭제된 메모까지 셈 → 살아있는 메모만 집계
- 상태바 줌 % 클릭 = 100% 리셋(별도 "맞춤" 버튼 분리)
- 표 CSV 복사 무피드백 → 토스트
- 이미지 정렬 버튼 무반응 → NodeSelection 상태에서 부모 문단에 정렬 적용
- 템플릿 "갱신" 무효 → 원클릭으로 현재 메모 내용 반영
- 명함 단건 vCard 파일명이 항상 동일 → 이름 기반
- QuickCapture 새 메모가 현재 워크스페이스에서 안 보임 → 귀속 + 저장 피드백
- 설정 모달 상태 메시지가 하단에만 → 상단에도 표시
- manifest 이중 경로(`/v2/v2/`) → 상대 경로
- 집중 모드 상태 칩(상태바)으로 "왜 UI가 사라졌지" 혼란 방지
- 공용 토스트 시스템(`lib/flash.ts`) 도입으로 window.alert 다수 대체

## 4. 핵심 기능 최고 수준 업그레이드

### 4-1. 그림판 (`PaintCanvas.tsx`, 161 → ~790줄)
- **Undo/Redo** 40단계 스택(Ctrl+Z/Y)
- **9개 도구**: 펜(필압 감지·베지어 곡선), 형광펜(반투명), 지우개, 채우기(스캔라인 flood fill), 직선, 화살표, 사각형, 타원, 텍스트
- 12색 팔레트 + 커스텀 색상 피커 + 최근 색상, 굵기 1–32 라이브 프리뷰
- 캔버스 3종 크기(내용 보존 리사이즈), Pointer Events(마우스·터치·펜)
- PNG 다운로드, 미저장 경고 가드, 전체 aria-label · 이모지 0

### 4-2. OCR (`OcrModal.tsx` 재작성 + `lib/ocr.ts` 확장)
- 파일 선택 + **드래그앤드롭 + 클립보드 붙여넣기**
- **다중 이미지 큐**(순차 처리, 항목별 진행률·신뢰도)
- **취소 버튼**(Tesseract worker terminate)
- 결과 편집 textarea + 클립보드 복사, 대형 이미지 자동 축소, HEIC 변환 유지
- 언어 선택 영속, CDN 실패 시 재시도

### 4-3. TTS/STT (`TTSButton.tsx`·`VoiceButton.tsx` 재작성 + `lib/speech.ts` 확장)
- **버튼이 툴바에 마운트조차 안 돼 있던 것을 발견** → 툴바에 추가
- TTS: 음성 선택(한국어 우선)·속도·피치 팝오버, 일시정지/재개, 문장 단위 청킹(Chrome 버그 회피), n/m 진행 표시
- STT: 실시간 중간 결과 오버레이, 녹음 표시 점멸+경과시간, 언어·연속모드·자동 문장부호, 인라인 오류 표시

### 4-4. 워드 기능 (요청: "최고 수준의 워드")
- **선택 영역 단위 글꼴·글자 크기**(12종 한/영 글꼴, 8–48pt) — 기존엔 전역 3종뿐
- **문단 줄 간격**(1.0–2.5) 선택
- **문단 들여쓰기/내어쓰기**(8단계, `Indent` 확장)
- **위/아래 첨자** 버튼(H₂O, X²)
- **링크 편집 팝오버**(Ctrl+K·버블툴바·메뉴 통합, window.prompt 대체)
- **특수문자 그리드 피커**(5개 그룹, prompt 대체)
- **실제 목차 삽입**(제목 기반, 앵커 링크 + 레벨별 들여쓰기)
- **표 셀 배경색**(5색 + 지우기)
- 서식 복사기(Ctrl+Shift+C/V)는 기존 배선 확인

## 6. 남은 항목 (다음 세션 후보)

### 조사 완료 / 남은 것
- **데이터 손실 의심 1건 — 재현 시도 결과 재현 안 됨 (조사 완료, 코드 변경 없음)**: 새 메모 생성 직후 타이핑 유실 시나리오를 5회 + 디바운스 경합(350ms 안에 전환) 4회, 총 9회 재현 시도했으나 **오염·유실 0건**. `scheduleEditorContentCommit`이 스케줄 시점의 `activeMemoIdRef`(메모 id)를 캡처하고 `flushPendingEditorContent`가 그 캡처된 id로 커밋하므로, 전환 후 늦게 flush돼도 올바른 메모에 저장됨(메모별 save-seq 카운터). QA가 본 1회성 증상은 그 수정 이전 상태이거나 HMR 리로드 중 편집기 재생성 타이밍으로 추정. **현재 코드에서는 안전한 것으로 확정.**
- **tiptap-pagination-plus `calculatePageCount` 에러**: Ctrl+1~9 메모 전환 시 반복 (언마운트 후 라이브러리가 비동기 페이지 계산). 기능 영향 없고 콘솔만 오염 — 라이브러리 레벨 이슈라 편집기 생명주기 회귀 위험 감안해 미수정 유지.
- **설정성 prompt 잔존** (자간·장평·단락간격·러닝헤더·포모도로 시간): 숫자 검증이 이미 있어 우선순위 낮음. 고마찰 8개(이미지URL·수식·Mermaid·임베드·YouTube·인용·참고문헌·웹검색)는 이번 세션에 앱 스타일 입력 모달(`lib/promptModal.tsx`)로 교체 완료.

### 미수정 결함 (QA 발견)
- **파일 열기 / 다른 이름으로 저장 침묵 실패**: File System Access API 예외를 삼킴 — try/catch + `input[type=file]` 폴백 + 실패 토스트 필요
- **첫 실행 역할팩 모달**: "그냥 메모장" 버튼이 모달을 안 닫고 빈 탭으로 전환 — 즉시 닫도록
- **논문 워크플로 완결성**: 인용 삽입 무반응 / 번호 재정렬 무피드백 / 학술 템플릿 0개
- **콜아웃 연속 삽입 시 중첩**: 삽입 후 커서가 콜아웃 내부에 남음 — 삽입 후 뒤 단락으로 이동 필요

### UX 부채 (묶음 처리 권장)
- **i18n 미작동**: 언어 선택기는 있으나 UI 문자열이 한국어 하드코딩 (전면 번역 필요)
- **window.prompt 잔존**: 수식·Mermaid·구분선 스타일·자간/장평·YouTube 등 — 팝오버로 순차 교체
- **결과 표시 채널 비일관**: 모달/새 탭(갤러리·워드클라우드)/alert 혼재 — 통일 필요
